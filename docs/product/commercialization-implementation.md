# 简连远程助手商业化实施说明

## 当前实现

第一阶段以不破坏 RustDesk 远控链路为原则，完成桌面客户端商业化入口：

- 新增“简连远程助手”桌面外壳和品牌导航。
- 首页复用 RustDesk 当前设备 ID、临时密码、快速连接和最近会话能力。
- 设备页复用 RustDesk 地址簿、账号登录和设备数据模型。
- 会员页提供个人版、企业版套餐与权益展示骨架。
- 设置入口继续使用 RustDesk 原有设置页面。
- 被控端精简模式继续使用原页面，避免改变窗口尺寸和服务控制行为。

主要代码位置：

- `flutter/lib/desktop/pages/simplelink_desktop_page.dart`
- `flutter/lib/desktop/pages/desktop_tab_page.dart`

## 后续实施顺序

### 第二阶段：商业 API 与账号

- 手机号和验证码登录。
- 用户资料与登录态刷新。
- 设备绑定、解绑、重命名和分组。
- 套餐、会员权益和权限下发。
- 连接记录上报。

### 第三阶段：订单与管理后台

- 订单、支付回调和会员生效。
- 用户、设备、套餐和订单管理。
- P2P、Relay、失败连接统计。
- hbbs、hbbr 和 API 服务状态监控。

### 第四阶段：移动端

- Android 登录与设备列表。
- Android 控制 Windows 电脑。
- Android 被控端和企业设备管理。

## 接口边界

商业 API 只负责账号、设备、权限、订单和统计。屏幕传输、输入控制、NAT 穿透、P2P 协商与 Relay 中继继续使用 RustDesk 原有实现，避免把业务系统耦合进远控协议。
