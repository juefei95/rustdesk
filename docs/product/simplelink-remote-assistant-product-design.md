# 简连远程助手产品设计方案

版本：V1.0

定位：基于 RustDesk 开源远程控制能力的商业化远程协助平台

---

# 1. 产品概述

## 产品定位

基于 RustDesk 开源远程桌面技术，打造面向个人用户、小企业、软件服务商的远程协助平台。

核心能力：

- 快速连接电脑
- 优先 P2P 直连
- 自动 Relay 中继
- 用户账号体系
- 设备管理
- 会员订阅

---

# 2. 技术架构

```
                管理后台

                    |

                 API服务

                    |

        -------------------------

        |                       |

     客户端                RustDesk服务端

                              |

                         hbbs + hbbr
```

RustDesk负责：

- 屏幕传输
- 鼠标键盘控制
- NAT穿透
- P2P连接
- 中继传输

商业系统新增：

- 用户系统
- 设备管理
- 权限控制
- 订单系统
- 数据统计

不直接复制 ToDesk。

↓

- 高客单价
- 竞争较小

# 11. 开源协议

基于 RustDesk AGPL-3.0。

需要：

- 保留版权声明
- 提供修改源码
- 提供源码获取方式

不要求：

- 合并官方仓库
- 提交Pull Request
